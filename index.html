Test Cases for "Add Toppings to Pizza" Feature

Dominos Pizza - QA Testing Documentation

Feature: Add toppings to a pizza

Test Date: December 29, 2025

Prepared by: QA Engineer - Viqtor Strog

QUESTIONS TO CLARIFY

Q1: Are there different pizza sizes (Medium, family, big, meter)?

→ Affects: Functional Testing #16, Negative Testing #89-90, Regression Testing #100

Q2: Is order button exists at all? What to do after pizza assembled? How to order?

→ Affects: Functional Testing #15, Integration Testing #75-80, Smoke Testing #102

Q3: Are there any incompatible topping restrictions that exist?

→ Affects: Functional Testing #13, Negative Testing #86

Q4: What is the maximum number of toppings allowed per pizza?

→ Affects: Negative Testing #81, Boundary Testing #90

Q5: Are there any toppings that can be out of stock?

→ Affects: Negative Testing #86

Q6: Do free toppings or promotional toppings exist?

→ Affects: Functional Testing #19-20

Q7: Is there an undo/redo functionality?

→ Affects: UI/UX Testing #34

Q8: Are topping categories organized (fish, vegetables, cheese)?

→ Affects: UI/UX Testing #31

FUNCTIONAL TESTING

CRUD Operations

1. Verify that user can select a single topping from available options (Create)
2. Check if user can deselect previously selected topping by clicking on it again (Delete)
3. Check if multiple toppings can be selected simultaneously (Create multiple)
4. Verify that removing all toppings returns pizza to the base state (Delete all)
5. Verify that each topping has quantity selection options (left, right half, full) (Update)
6. Check if quantity topping changes pizza visual representation (Update)
7. Verify that topping selection saves when switching between pizza customization sections (Read/Persistence)
8. Verify that close button saves toppings selection when clicking and reopening (Read/Persistence)
